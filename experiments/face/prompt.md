プロンプト1
5人の正面顔写真を使って顔認証モデルを構築してください。各人物につき画像は1枚しか存在しないため、大量のデータ拡張を必ず行うことを絶対条件とします。

【使用するモデル】
1. 顔検出・アライメント：MTCNN を使用して顔領域を抽出し、目の位置でアライメントを行う。
2. 埋め込みモデル：ArcFace（ResNet100）を使用して 512 次元の顔埋め込みを生成する。
3. 類似度判定：コサイン類似度で人物識別を行う。

【データ拡張】
各人物につき最低 300〜500 枚の拡張画像を生成すること。
必須の拡張：
- 左右反転
- 明度・彩度・コントラストのランダム変化（ColorJitter）
- ガウシアンノイズ付与（σ=0.01〜0.05）
- 画像の回転（±5〜15度）
- ランダムクロップ＋リサイズ
- GaussianBlur
- シャープ化
- JPEG圧縮ノイズ（品質 60〜95）
- ランダムアフィン変換（平行移動・微小スケール変化）

任意の拡張：
- GANベースの擬似的な表情変化
- 背景の軽微な変化
- Cutout（顔の一部に小さな欠損を入れる）

【学習方法】
- ArcFace の埋め込みを用いて人物ごとのプロトタイプ（平均ベクトル）を作成し、Few-shot 学習で識別器を構築する。
- 過学習防止のため L2 正則化、Dropout、Early stopping を使用する。

【最終的に出力する内容】
1. 使用したデータ拡張の一覧と設定値
2. モデル構造（MTCNN＋ArcFace）の説明
3. 学習手順（Few-shot / 転移学習）
4. 推論方法（embedding＋コサイン類似度）
5. 評価方法（類似度分布・混同行列など）
6. 改善案


プロンプト2
5人の正面顔写真を使って顔認証モデルを構築してください。各人物につき画像は1枚しか存在しないため、大量のデータ拡張を必ず行うことを絶対条件とします。

【使用するモデル】
1. 顔検出：MediaPipe Face Detection を使用する（MTCNNは禁止、重いため）。
2. 顔アライメント：MediaPipe Face Mesh の目の位置を使って簡易アライメントを行う。
3. 埋め込みモデル：MobileFaceNet を使用して 128 次元の顔埋め込みを生成する（ArcFace/ResNet100は禁止）。
4. 類似度判定：コサイン類似度で人物識別を行う。

【データ拡張】
各人物につき最低 150〜250 枚の拡張画像を生成すること（8GB RAM のため上限を下げる）。
必須の拡張：
- 左右反転
- 明度・彩度・コントラストのランダム変化（ColorJitter）
- ガウシアンノイズ付与（σ=0.01〜0.05）
- 画像の回転（±5〜10度）
- ランダムクロップ＋リサイズ
- GaussianBlur
- JPEG圧縮ノイズ（品質 70〜95）

任意の拡張：
- 背景の軽微なノイズ追加
- Cutout（小さな欠損）

【学習方法】
- MobileFaceNet の埋め込みを用いて人物ごとのプロトタイプ（平均ベクトル）を作成する。
- 分類器は k-NN または SVM を使用する（ArcFace の分類層は使わない）。
- 過学習防止のため L2 正則化と Early stopping を使用する。

【最終的に出力する内容】
1. 使用したデータ拡張の一覧と設定値
2. モデル構造（MediaPipe＋MobileFaceNet）の説明
3. 学習手順（Few-shot）
4. 推論方法（embedding＋コサイン類似度）
5. 評価方法（類似度分布・混同行列など）
6. 改善案
